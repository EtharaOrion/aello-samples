## Corpus

Real web text plus two real held-out sources, all environment-provided. Training slice: Hugging Face `allenai/c4`, config `en.noclean`, pinned by dataset revision SHA, a fixed 12 GB shard selected by whole-file shard index and written to environment/data/raw/ with a SHA-256 manifest. Licence ODC-By 1.0 for the C4 release, with the underlying Common Crawl terms of use recorded in the licence chain. The noclean config is chosen deliberately because it retains real duplication, boilerplate and low-quality text, which is the substrate a curation task needs. Private evaluation shards: shard P1 from `wikimedia/wikipedia` config 20231101.en (CC BY-SA, GFDL) and shard P2 from `allenai/peS2o` (ODC-By 1.0), both pinned by revision SHA, both written only into tests/heldout/, disjoint from anything the agent can read. Acquisition: pod downloads pinned revisions once at authoring; the agent never downloads the graded corpus, per the requirements/aello-prd.md reconciliation that open egress covers packages and tooling while the graded corpus is environment-provided. environment/decontam/heldout_fingerprints.bin ships a one-way sorted hash set of normalised 13-grams of both held-out shards, so decontamination is implementable without exposing held-out bytes.
